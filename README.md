# Eric Opoka — Portfolio

A static portfolio starter for Eric Opoka.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Before publishing
1. Replace the placeholder email with your real professional email.
2. Replace the GitHub and LinkedIn links with your actual profiles.
3. Add project repository/live-demo links as they become available.
4. Add a professional headshot only if you want one.
5. Deploy to GitHub Pages, Vercel, Netlify, or another static host.

The site deliberately presents the portfolio around the specialization:
**Backend Software Engineering with Python + AI/ML.**
